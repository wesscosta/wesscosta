## 👨‍💻 Sobre mim

Sou engenheiro de software, professor do **SENAC** e fundador da
**Verit Soluções Digitais**.

Atuo no desenvolvimento de aplicações web e sistemas corporativos utilizando
**Python, Django, React, PostgreSQL e Docker**, com foco em APIs, arquitetura
de software, soluções SaaS e aplicações multi-tenant.

Também ensino programação, banco de dados, redes de computadores,
infraestrutura e inteligência artificial, conectando conceitos técnicos
a projetos e problemas reais.

> “What we have to learn to do, we learn by doing.” — Aristotle

---

## 🚀 Atualmente

- Desenvolvendo o **VeryBlue ERP**, uma plataforma empresarial multi-tenant;
- criando aplicações e APIs com **Django REST Framework e React**;
- trabalhando com monitoramento utilizando **Prometheus, Grafana e Zabbix**;
- produzindo laboratórios e materiais para educação profissional;
- estudando arquitetura de software, inteligência artificial e DevOps.
