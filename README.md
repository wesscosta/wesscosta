## 👨‍💻 Sobre mim

Sou engenheiro de software, professor de tecnologia no **SENAC Piauí** e fundador da **Verit Soluções Digitais**.

Atuo no desenvolvimento de aplicações web e sistemas corporativos utilizando **Python, Django, React, PostgreSQL e Docker**, com foco em APIs REST, arquitetura de software, plataformas SaaS e aplicações multi-tenant.

Também ensino programação, banco de dados, redes de computadores, infraestrutura e inteligência artificial, conectando fundamentos técnicos a projetos e problemas reais.

> “What we have to learn to do, we learn by doing.” — Aristotle

---

## 🚀 Atualmente

* Desenvolvendo o **VeryBlue ERP**, uma plataforma empresarial SaaS multi-tenant;
* criando aplicações e APIs com **Django REST Framework e React**;
* trabalhando com infraestrutura, observabilidade e monitoramento;
* produzindo laboratórios e materiais para educação profissional;
* mantendo a **[Arena PI Tech](https://github.com/arenapitech)**, organização dedicada a projetos e repositórios educacionais;
* aprofundando meus estudos em arquitetura de software, inteligência artificial, Java e DevOps.
